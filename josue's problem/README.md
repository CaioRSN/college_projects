Your role, young programmer, is to assist Dora and Josué on this journey by building a program that collects information and confirms the story's veracity through the validation of structures composed of parentheses, braces, and brackets.
Your program must receive information of the following types:
Identity: contains the words jesus, isaias, or moises in its scope.
Address: contains the words sertao or bom jesus.
Memory: If it does not fit any of the above.
Each type of information must be converted into a specific character type:
Identity -> Parentheses: ( or )
Address -> Braces: { or }
Memory -> Brackets: [ or ]
